# 🀄 麻雀多面待ちトレーニング

7枚の手牌から、アガリ牌（待ち牌）をすべて当てるブラウザゲームです。複数の牌で待つ「多面待ち」の読みを、60秒のタイムアタックで鍛えられます。

## 遊び方

1. [`game/麻雀トレーニング　バージョン2.html`](game/%E9%BA%BB%E9%9B%80%E3%83%88%E3%83%AC%E3%83%BC%E3%83%8B%E3%83%B3%E3%82%B0%E3%80%80%E3%83%90%E3%83%BC%E3%82%B8%E3%83%A7%E3%83%B32.html) をブラウザで開く（ダウンロードしてダブルクリックでも可）
2. 「スタート」を押す
3. 手牌（7枚）を見て、待ち牌をすべてクリックで選択する
4. 「回答」で答え合わせ。分からなければ「スキップ」で正解を確認できる

## ルール

| 項目 | 内容 |
| --- | --- |
| クリア条件 | 3問正解 |
| 制限時間 | 60秒 |
| ペナルティ | 不正解で −5秒 |
| 使用牌 | 萬子（一〜九）と字牌のみ |
| 対象の形 | 4面子＋1雀頭（七対子・国士無双は対象外） |

## 特長

- インストール不要。HTMLファイル1つで動作
- 問題は毎回ランダム生成（待ちは1〜4種類）
- スマートフォンの画面幅にも対応
